## What is Professional Gauge Converter?

The Professional Gauge Converter is a free web tool that instantly converts between American Wire Gauge (AWG) sizes, millimeters, and inches for body piercing jewelry. When a user selects a gauge value from the dropdown (e.g., 16G), the tool automatically calculates the equivalent in millimeters (1.2mm) and inches (0.047in), and displays a life-size circle representing the actual diameter. The tool supports 14 standard gauge sizes from 00G (10.0mm) down to 22G (0.6mm), covering all common body piercing jewelry thicknesses.

The converter works bidirectionally: entering a millimeter value automatically finds the closest gauge size, and entering inches converts to both mm and gauge. A comprehensive reference table organizes recommended gauge sizes by piercing type, including ear piercings (tragus, helix, daith, rook), facial piercings (nostril, septum, eyebrow, bridge), oral piercings (labret, tongue, medusa), body piercings (navel, nipple, surface), and genital piercings (Prince Albert, frenum, VCH, Christina). Each table row is clickable to auto-fill the converter with that size.

The tool includes a dark/light mode toggle, an embed feature for studio websites, and a documentation tab with complete usage instructions. It is developed by Patrick Poli, inventor of BioFlex, and uses REACH-compliant sizing standards.

## How to Use

**Step 1: Select a Gauge Size**
Click the "Gauge Size" dropdown menu. Choose from 14 options: 00G (10.0mm), 0G (8.0mm), 1G (7.0mm), 2G (6.0mm), 4G (5.0mm), 6G (4.0mm), 8G (3.2mm), 10G (2.4mm), 12G (2.0mm), 14G (1.6mm), 16G (1.2mm), 18G (1.0mm), 20G (0.8mm), or 22G (0.6mm). The tool instantly converts to millimeters and inches.

**Step 2: Enter Millimeters Directly**
Type a decimal value in the "Millimeters (mm)" input field. The tool accepts values from 0 to 20mm with 0.1mm increments. It automatically finds the closest gauge size and converts to inches.

**Step 3: Enter Inches Directly**
Type a decimal value in the "Inches (in)" input field. The tool accepts values from 0 to 1 inch with 0.001 inch increments. It converts to millimeters and finds the closest gauge size.

**Step 4: View the Visual Display**
Watch the SVG circle update to show the actual diameter of the selected size. The circle scales proportionally within a 300x300 pixel viewport, with a maximum radius of 140 pixels.

**Step 5: Read the Measurement Panel**
Three display boxes show the current gauge, millimeter, and inch values. Each updates in real-time as you change any input.

**Step 6: Use the Reference Tables**
Scroll to the "Quick Reference Guide" section. Click any row in the Ear & Facial Piercings table or Body & Oral Piercings table to auto-fill the converter with that size.

**Step 7: Toggle Dark Mode**
Click the dark mode toggle button (moon/sun icon) to switch between light and dark themes. Your preference is saved locally.

## Frequently Asked Questions (FAQ)

**Q1: What gauge sizes does this converter support?**
A: The converter supports 14 standard AWG sizes: 00G (10.0mm), 0G (8.0mm), 1G (7.0mm), 2G (6.0mm), 4G (5.0mm), 6G (4.0mm), 8G (3.2mm), 10G (2.4mm), 12G (2.0mm), 14G (1.6mm), 16G (1.2mm), 18G (1.0mm), 20G (0.8mm), and 22G (0.6mm).

**Q2: Can I convert from millimeters to gauge?**
A: Yes. Enter any millimeter value between 0 and 20mm, and the tool automatically finds the closest gauge size. It uses exact matches when available and nearest-neighbor matching for non-standard values.

**Q3: Is 16G bigger than 14G?**
A: No. In the AWG system, lower numbers indicate larger diameters. 14G (1.6mm) is thicker than 16G (1.2mm). The gauge number and physical size are inversely related.

**Q4: What is the most common piercing gauge?**
A: 14G (1.6mm) is standard for navels, nipples, tongues, and industrial piercings. 16G (1.2mm) is common for most ear and facial piercings including tragus, helix, daith, rook, septum, and eyebrow. 18G (1.0mm) or 20G (0.8mm) is standard for earlobes and nostril piercings.

**Q5: Does the visual circle show actual size?**
A: The circle is scaled to represent the actual diameter proportionally. The SVG viewport is 300x300 pixels with a maximum circle radius of 140 pixels. The circle scales using a conversion factor of 3.78 pixels per millimeter.

**Q6: Can I embed this tool on my studio website?**
A: Yes. Click the "Embed Code" tab to get an iframe code. Copy the provided HTML and paste it into your website. The embed is responsive and includes all conversion functionality.

**Q7: Does the tool work on mobile devices?**
A: Yes. The converter is fully responsive with touch-optimized controls. The three-column input layout stacks vertically on smaller screens. The visual display and measurement panel remain accessible.

**Q8: What happens if I enter an invalid value?**
A: The tool shows an error message in a red alert box. For millimeters, it validates values between 0 and 20mm. For inches, it validates between 0 and 1 inch. Errors auto-hide after 5 seconds.

**Q9: Does the reference table cover genital piercings?**
A: Yes. The Body & Oral Piercings table includes Prince Albert (14G), frenum (12G), VCH (12G), and Christina (12G) piercings with their standard gauge sizes.

**Q10: Can I use this for stretching?**
A: Yes. The converter is useful for planning stretching progressions. Always ensure the millimeter difference between current and target size does not exceed 1mm for safe stretching.
